## 個人回答

### 問題一
測試一中，`board_list` 整理後為 `['amy', 'ben', 'amy', 'cora']` 共 4 筆，但桌遊應以 3 人計費，因為 `'amy'` 在同一場活動出現了兩次；依規則同一人於同一場重複報名只算一位參加者、只收一次該場費用，去重後為 `['amy', 'ben', 'cora']` 共 3 人。

直接把字串拆成 `list`，**保留了**原始報名順序與重複出現的次數，方便觀察是否有重複填單；但**失去了**不重複性，若直接用長度算錢會多收重複報名的費用。轉成 `set` 後，**保留了**去重後的參加者名單，利於做交集、聯集與差集比較；但**失去了**原本的順序與重複次數。

### 問題二
測試三中，桌遊與電影去重後皆為 `{'amy', 'ben', 'cora'}`，只有 3 位不同的人：
- 聯集 `board_set | movie_set = {'amy', 'ben', 'cora'}`，**總不重複人數**為 $3$ 人。
- 交集 `board_set & movie_set = {'amy', 'ben', 'cora'}`，**共同參加者**有 $3$ 人（`['amy', 'ben', 'cora']`），兩個差集 `board_set - movie_set` 與 `movie_set - board_set` 皆為空集合（顯示為 `[]`）。
- 由於這 3 人各參加了兩場活動，**報名人次**為兩場去重人數相加：$3 + 3 = 6$ 人次。
- 兩場分別計費後相加，**總應收**為：
  $$3 \times 120 + 3 \times 80 = 360 + 240 = 600\text{ 元}$$
